# 로컬 LLM 전사 다듬기·요약 정책

## 상태

이 문서는 현재 TalkTracker에 적용된 전사 다듬기·요약 흐름을 설명한다. 구현은 Agent Chat Desktop 최신 소스의 텍스트 첨부 정책을 따른다. 원본 전사문은 AI 처리 전후에도 변경하지 않으며, AI가 만든 결과는 별도 Markdown 문서로 보관한다.

## 처리 흐름

1. 분석 결과에서 사람이 읽을 수 있는 원본 전사문을 만든다.
2. 전사문을 작업 중에만 임시 Markdown 파일로 만든다.
3. 임시 파일의 크기가 5MiB를 넘으면 모델에 보내지 않고 안내한다.
4. 240KiB 이하의 전사문은 전체를 하나의 첨부 문서로 보낸다.
5. 더 긴 전사문은 16KiB 목표 크기의 문서 단위로 나눈다.
6. 사용자 요청과 대화 목적·배경에서 추출한 단어로 관련 단위를 고르고, 앞·뒤 문맥 단위도 함께 넣어 최대 240KiB를 한 번에 보낸다.
7. 관련 단위를 찾지 못하면 앞 70%·뒤 30% 발췌본과 표시 문구를 보낸다.
8. 모델의 자유 형식 Markdown 응답을 다듬은 대화 또는 요약 문서로 그대로 보관한다.
9. 성공, 오류, 사용자 중단 어느 경우에도 임시 파일과 임시 폴더를 정리한다.

## Agent Chat 호환 한도와 선택 규칙

| 항목 | 값 | 적용 방식 |
| --- | ---: | --- |
| 임시 전사 파일 | 5MiB | 초과하면 모델 요청 전에 중단 |
| 모델 전달 본문 | 240KiB | 한 전사문이 사용할 수 있는 본문 예산 |
| 문서 단위 목표 | 16KiB | 단락·제목을 우선 보존하고 문장 경계를 사용 |
| 선택 계산 여유 | 8KiB | 문서 단위 표지와 선택 설명을 위한 예산 |
| 문맥 앵커 | 사용 가능 예산의 30% | 처음·마지막 단위를 번갈아 포함 |
| 관련성 점수 | 제목 일치 8점, 본문 일치 최대 6점 | 관련 단위와 인접 단위를 우선 선택 |
| 관련성 없음 | 앞 70%·뒤 30% | 발췌본 안내 문구 포함 |

문서가 잘린 경우 결과 화면에는 `문서 N개 단위 중 M개 전달` 또는 `앞·뒤 발췌본 전달`을 표시한다. 이 표시는 모델에 실제로 전달한 전사문 범위를 알려 주며, 원본 전사문을 변경하지 않는다.

## 모델 요청

모델에는 다음 한 개의 사용자 메시지를 보낸다.

```text
[첨부 파일: <원본이름>-전사문.md]
<선택된 전사문>
[첨부 파일 끝]

[사용자 요청]
<다듬기 또는 요약 지시, 대화 목적·배경, 화자 안내>
```

- 응답은 JSON이나 구간 ID를 요구하지 않는다.
- `max_tokens`를 강제하지 않는다.
- 결과 만들기에서 요청마다 `기본(서버 설정)`, `medium`, `low`, `none`을 선택한다. 기본은 `reasoning_effort`를 요청에 넣지 않고, 나머지는 선택한 값만 넣는다.
- 응답 길이·추론 강도를 바꿔 재시도하지 않는다. 선택한 강도를 지원하지 않는 서버에는 기본값으로 되돌아가지 않고 오류를 안내한다.
- 여러 모델 요청으로 나누거나 부분 요약을 재결합하지 않는다.
- 서버가 자체 출력 한도에 도달했지만 텍스트를 반환한 경우, 반환된 자유 형식 결과를 보관한다.

## 결과와 안전성

- **원본 전사**: 분석 결과 그대로 보존한다.
- **다듬은 대화**: 모델이 반환한 Markdown을 별도 문서로 보관한다.
- **요약**: 모델이 반환한 Markdown을 별도 문서로 보관한다.
- 대화 목적·배경과 화자 안내는 현재 요청에만 사용하며 결과 문서에 자동으로 넣지 않는다.
- API 키는 설정, 결과 문서, 오류 메시지에 저장하지 않는다.
- 취소·실패 시 원본 전사와 이전에 만든 AI 결과는 유지한다.

## 검증 범위

- 18KiB 한국어 전사문이 전체 첨부로 전달되는지
- 긴 전사문에서 관련 단위·앞뒤 문맥 선택과 발췌본 대체가 동작하는지
- 5MiB 파일 한도를 모델 요청 전에 확인하는지
- 임시 전사 파일이 성공·오류·중단 뒤 정리되는지
- 첨부 요청이 JSON 모드, 강제 응답 길이, 자동 추론 조정 없이 전송되고 선택한 추론 강도만 반영하는지
- 웹·데스크톱에서 원본, 다듬은 대화, 요약을 분리해 표시·저장하는지
