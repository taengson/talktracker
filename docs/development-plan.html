개발 단계

0

환경 검증

현재 PC에서 두 모델을 실제로 불러오고, 1~5분 길이의 파일을 끝까지 처리할 수 있는지 먼저 확인합니다.

  • Windows·Python·FFmpeg·PyTorch 및 CPU/GPU 상태 확인
  • Nemotron 다운로드와 Whisper Turbo 단독 실행 확인
  • CPU 및 NVIDIA GPU에서 처리 시간·메모리 기록

완료 기준 하나의 로컬 WAV에서 전사와 화자 구간이 모두 생성된다.

1

처리 엔진 프로토타입

명령 한 번으로 파일에서 화자별 대화 기록을 생성합니다.

  • 파일 검사·오디오 변환
  • Whisper 단어/문장 시간 정보와 Nemotron 화자 구간 추출
  • 시간 겹침 기준 화자 배정, 짧은 구간 병합, 동시 발화 보존

완료 기준 화자·시작/종료 시각·전사문을 가진 내부 대화 기록이 생성된다.

2

결과 내보내기

읽기용 대본, 자막, 재처리용 원본 데이터를 각각 제공합니다.

  • Markdown: 메모 앱이나 문서 도구에서 계속 편집할 수 있는 대화 기록
  • HTML: 브라우저에서 편하게 읽고 인쇄 또는 PDF로 보관할 수 있는 문서

완료 기준 두 문서의 시간순·화자 라벨·본문이 일관된다.

3

로컬 사용자 화면

터미널을 쓰지 않고도 파일 선택부터 내보내기까지 마칩니다.

  • 드래그 앤 드롭, 처리 단계·진행 상태 표시
  • 화자 라벨 이름 변경, 시간 기준 대화 기록 검토
  • Markdown 저장, HTML 문서 열기, 인쇄 또는 PDF 저장
  • 모델·CPU/GPU 설정은 사용자가 고르지 않고 앱이 알아서 처리

완료 기준 처음 쓰는 사용자도 파일 하나를 넣어 결과를 저장할 수 있다.

4

품질·성능 보완

실제 회의와 인터뷰에서 발생하는 겹침·잡음·긴 파일 문제를 다듬습니다.

  • 한국어 회의, 인터뷰, 다인 대화, 잡음 샘플 검증
  • Turbo와 large-v3의 품질·처리 시간 비교
  • 중간 결과 보존과 실패 후 재시도

완료 기준 대표 샘플별 한계와 권장 설정이 사용자 문서에 정리된다.

화자-전사 시간 결합 규칙

  1. Whisper가 만든 단어 또는 문장의 시작·종료 시간을 읽는다.
  2. 같은 시간대의 Nemotron 화자 구간을 찾는다.
  3. 겹치는 시간이 가장 긴 화자를 기본 화자로 지정한다.
  4. 두 화자가 충분히 겹치면 두 라벨과 overlap: true를 기록한다.
  5. 인접한 같은 화자의 짧은 조각은 문장 흐름을 해치지 않는 범위에서 병합한다.
  6. 어떤 화자 구간에도 속하지 않는 전사문은 알 수 없음으로 보존한다.

주요 위험과 대응

위험대응
우선Windows에서 Nemotron 의존성 호환 문제개발 시작 전 단계 0에서 실제 PC로 검증하고, Python/Transformers 경로를 우선 사용한다.
주의GPU가 없거나 VRAM 부족CPU 모드를 제공하고 Turbo를 기본으로 한다. 필요하면 medium을 대안으로 둔다.
주의동시 발화·잡음겹침을 보존하고, 결과 화면에서 화자 라벨과 문장을 수정할 수 있게 한다.
관리화자 번호가 파일마다 달라짐파일별 익명 라벨을 기본으로 하고 사용자가 이름을 붙이게 한다.
주의긴 파일에서 실패·메모리 부족청크 처리와 단계별 임시 결과 저장, 재시도 기능을 둔다.
